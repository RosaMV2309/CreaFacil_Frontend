# CreaFacil_Frontend

Aplicación móvil del cliente de **CreaFácil**: aplicación multiplataforma para la gestión de pedidos, cotizaciones y planificación de trabajos personalizados (manualidades, decoraciones y murales).

- Tecnología: Flutter (Android y web)
- Especificación: DERCAS v1.0 (Rosa Virginia Moreira Vidal, Sexto B)

## Ramas

- `main`: versiones estables.
- `develop`: integración. Todo cambio entra por Pull Request desde `feature/*`, `fix/*` o `refactor/*`.
